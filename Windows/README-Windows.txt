PrismArt for Windows x64

1. Extract the entire ZIP to a folder.
2. Run PrismArt.exe from that folder. Keep primitive.exe beside it.
3. Open, paste, or drag an image into the app.
4. Choose a preset or adjust shapes (up to 20,000), analysis size, output size, and opacity.
5. Use Quick preview, then Generate full quality to save PNG, JPEG, or SVG.

The ZIP includes the .NET runtime and Primitive engine. No Go or .NET installation is needed.
Rendering stays on your computer. The app does not upload images.

Windows currently supports PNG, JPEG, BMP, GIF, TIFF, and formats supported by Windows imaging. Animated GIF export and HEIC input are not included in this version.
For very complex images, try Triangle or Polygon with 2,000–5,000 shapes first. 20,000 shapes can take substantially longer. Bezier draws line-like shapes and can obscure fine details at high counts.
